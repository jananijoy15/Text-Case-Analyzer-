🔤 Text Case & Format Analyzer

Text Case & Format Analyzer is a simple web-based Text Analysis application that converts text into different letter cases and provides basic text statistics.

Live Application Link 
https://jananijoy15.github.io/Text-Case-Analyzer-/

✨ Features

- 🔠 Convert text to UPPERCASE
- 🔡 Convert text to lowercase
- 📝 Convert text to Title Case
- 📄 Convert text to Sentence Case
- 🔢 Count words
- 🔤 Count characters
- 📋 Easy copy-and-use output
- 📱 Mobile-friendly responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter or paste text into the text area.
3. Select the required text format.
4. The text is converted instantly.
5. View the formatted text and statistics.

🔤 Available Text Formats

Format| Description
UPPERCASE| Converts all letters to capital letters
lowercase| Converts all letters to small letters
Title Case| Capitalizes the first letter of each word
Sentence Case| Capitalizes the beginning of sentences

💡 Example

Input:

hello welcome to text analysis

Title Case:

Hello Welcome To Text Analysis

UPPERCASE:

HELLO WELCOME TO TEXT ANALYSIS

lowercase:

hello welcome to text analysis
